# Privacy — development candidate

The current build stores village progress and audio/language settings locally in the application's Godot user data directory. There is no account, server, analytics, network permission, purchase SDK or advertising SDK. The developer receives no gameplay data through this application. Removing app data or uninstalling removes local progress; there is no cloud recovery.

This describes this ad-free source revision only. Android/Google platform services and device-level backup are outside the game's own application logic. Before distribution, confirm the final manifest and platform backup settings, provide a real support contact and hosted privacy policy, complete Play Data Safety declarations from the actual binary, and review children/audience declarations. Ad integration requires an updated policy and verified consent handling before inclusion.
