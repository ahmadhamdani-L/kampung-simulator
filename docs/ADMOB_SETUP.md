# AdMob boundary

This candidate is intentionally ad-free. No SDK, advertising ID permission, network request or fabricated ad reward is included. `VillageAds` exposes an unavailable signal by default. Verified callback tokens are consumed exactly once in adapter tests. Setting readiness flags alone is not native integration and must never be exposed as a gameplay control.

Before ads: choose and pin a maintained Godot Android plugin; audit its SDK and license; add official Google sample application/unit IDs only in development configuration; integrate native lifecycle/error callbacks and offline timeouts; add a UMP consent flow where required; update permissions, privacy/Data Safety declarations and tests. A completed native rewarded callback must be the sole trigger for reward delivery. Interstitials need a recorded last-show timestamp, a natural break and at least a five-minute cap.

Production AdMob IDs and consent decisions have not been provisioned. No claim of advertising-policy compliance or native monetization readiness is made.

Review primary documentation before enabling: [Google Mobile Ads](https://developers.google.com/admob/android/quick-start), [test ads](https://developers.google.com/admob/android/test-ads), [privacy/consent](https://developers.google.com/admob/android/privacy), [AdMob policies](https://support.google.com/admob/answer/6128543). No ad revenue is necessary to play.
